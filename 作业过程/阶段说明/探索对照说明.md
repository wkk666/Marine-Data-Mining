# 本轮探索对照的运行说明

本轮使用同一片**模拟**海区和四组模拟点，保留旧脚本与上一轮结果。新代码没有时间窗、实时更新、最终答案缓存或完整选择器。

## 运行命令

依赖沿用本目录 `.runtime/packages` 的 H3 4.5.0、Shapely 2.2.0、NumPy 2.3.5，旧的 `requirements.txt` 保持不变。在本目录使用本机已安装的 Python：

```powershell
& 'C:\Users\wkc\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' '.\exploration_experiment.py'
```

测试生成规则和计时隔离：

```powershell
& 'C:\Users\wkc\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' '.\test_exploration.py'
```

代码自动加载同目录的独立依赖。新运行目录为 `runs/explore_时间戳/`；`LATEST_EXPLORATION.txt` 指向最新探索运行。旧的 `LATEST_RUN.txt`、旧摘要和旧运行目录不覆盖。

## 运行前固定的规则

完整协议在 `exploration_protocol.json`，在数据生成与性能计时前已写盘。每次运行先复制协议并保存时间戳与 SHA-256；结束后再次检查协议字节没有变化。结果不用于调整本轮参数。

| 数据 | 分布 | 新随机种子 |
| --- | --- | ---: |
| uniform_A | 原范围内经纬度独立均匀 | 20261121 |
| uniform_B | 原范围内经纬度独立均匀 | 20261122 |
| boundary_A | 80%边界带 + 20%背景均匀 | 20261123 |
| boundary_B | 80%边界带 + 20%背景均匀 | 20261124 |

每组均为 10,000 个随机点，加原有 32 个边界测试点，记录 ID 唯一。

边界带宽：距海区边界不超过 **0.002度**，距离使用与前次查询相同的经纬度平面欧氏距离，不将其称为精确固定米数。聚集部分内、外侧各 4,000 点；背景均匀点 2,000 点。背景点也可能落入边界带，因此“80%”是混合生成成分比例，不是最终带内点数恰好占80%。

生成方式：从原矩形范围均匀提出候选点，拒绝距边界超过带宽的点；分别保留最先满足条件的 4,000 个区内点和 4,000 个区外点，合并背景点后随机打乱。拒绝采样、数据保存都不计入查询时间。顶点和边中点等 32 个原测试点最后加入，不改变。

## 正确性与实测总时间

原 `run_experiment.py` 中的 `prepare_method`、`query`、覆盖方法和直接几何对照原样导入。直接对照仍有外包矩形初筛、向量化精判及几何预处理。H3 每档独立从原始经纬度编码，完整相交格覆盖，边界点精判并纳入。

先对每组检查四方案 ID 集合、误选/漏选、32 个边界点，以及覆盖格并集和扩大矩形枚举。正确性失败时原代码先保存诊断，并中止本轮性能测量。

K 为 **1、100、1000**，每个“数据×方法×K”组合重复 **7次**。每个试次重新准备，外层计时器在准备前启动，在第K次查询返回后停止。每次都正常构造 ID 返回数组，未缓存最终答案。外层总时间包括循环和原查询自身的计时、指标构造开销，不以分项之和替代实测。

四组、三档K、四方案在每轮中随机打乱。库预热允许，完整索引和清单不跨试次复用；GC统一暂停，结束后恢复。输入数组在计时阶段只读。正确性集合比较在计时之外：先完整预检，每个试次结束再核对最后一次返回值。另有测试确认查询被调用K次且每次确实创建新的结果数组。

全部作为探索数据。事后从直接/r7的中位数中取最小值，再从全部四方法的中位数中取最小值，二者之差是增加选项的潜在节省。不是取所有单次运行里最小的偶然值，也不是实际选择器收益。

波动同时保存第25、75百分位数、最小值、最大值和中位绝对偏差。四种方法的完整波动表和每次原始计时均保存。单凭微小中位数差异不认定稳定优势。

## 200条样本费用

每组 **31次**。每次用独立、事先规定的种子从10,032条原始记录中不放回抽200条，保存种子和记录ID。只计：

1. 随机数生成器初始化、抽样和坐标提取。
2. r6/r7/r8分别从样本原始经纬度编码。
3. 各档对样本涉及的格子编号去重。
4. 为这些去重格子新建轮廓，相对海区做相交及覆盖分类。

此函数只接收原始点与预处理后的海区几何，不接收全量点索引或完整海区覆盖清单，也不调用相应准备函数。测试会禁止这两个全量函数，确认样本特征仍能独立完成。

共同几何创建与预处理在特征计时前另行测量并保存。未来若同一几何确实复用，不重复收取这笔费用。样本费用只是一部分选择成本，未包含预测、决策等完整选择器费用。

## 主要输出

- `protocol.json`、`protocol_record.json`：运行前协议与指纹。
- `datasets/`：四组模拟数据、规则、各方案编码与覆盖、选中ID和正确性。
- `whole_batch_trials.csv`：336条整体实测记录，含准备和连续查询时段。
- `whole_batch_summary.csv`：48个“数据×K×方法”的中位数与波动。
- `posthoc_comparisons.csv`：12个“数据×K”的二选一/四选一对照及潜在节省。
- `feature_trials.csv`、`feature_summary.csv`：124次样本成本记录、分项及汇总。
- `探索结果.md`：简洁对照表、完整波动表和计时口径。
- 环境信息、源码快照、旧文件指纹、输出指纹：用于复现和检查上一轮未改动。

后续验证选择规则必须使用新的数据。本轮不写完整报告，不发布 GitHub。
