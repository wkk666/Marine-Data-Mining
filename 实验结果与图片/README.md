# 实验结果与图片

[最终验证结果](统计结果/独立验证结果.md)列出全部 18 个场景的中位数和第25—75百分位。[结果要点与净节省表](统计结果/结果要点与净节省表.md)、[计时汇总](统计结果/summary.csv)、[策略比较](统计结果/comparisons.csv)和[正确性](统计结果/correctness.json)便于复核报告。

两个总时间中位数之差和同轮差值的中位数分别保存在比较表中。净节省统一按对照减策略计算。

完整原始证据位于[最终验证运行目录](../实验代码/H3_海区查询实验/runs/validation_20261111_151150_257869/)，包括[882 条正式计时](../实验代码/H3_海区查询实验/runs/validation_20261111_151150_257869/formal_trials.csv)、[同轮原始差值](../实验代码/H3_海区查询实验/runs/validation_20261111_151150_257869/paired_differences.csv)、[保存的推荐](../实验代码/H3_海区查询实验/runs/validation_20261111_151150_257869/prerecommendations.jsonl)、[协议](../实验代码/H3_海区查询实验/runs/validation_20261111_151150_257869/protocol.json)及[快照](../实验代码/H3_海区查询实验/runs/validation_20261111_151150_257869/snapshots/)。

图稿沿用报告正文版。图3a至3d保留各自的全部场景及七轮原始差值。字段和统计口径见[图表数据来源说明](../实验代码/H3_海区查询实验/报告材料/图表数据来源说明.md)。
